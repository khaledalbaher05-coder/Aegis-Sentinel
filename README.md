# Aegis Sentinel Framework

**Aegis Sentinel** هو أداة أمنية مؤتمتة تعتمد على تيليجرام، مصممة لإجراء فحوصات أمنية سريعة للمنافذ (Port Scanning) وتوليد تقارير احترافية بصيغة PDF.

## 🚀 المميزات
* **فحص أمني مؤتمت:** فحص دقيق للمنافذ (TCP/UDP) باستخدام Nmap.
* **توليد تقارير PDF:** تحويل نتائج الفحص إلى مستندات منظمة وجاهزة للمشاركة.
* **واجهة تفاعلية:** تحكم كامل عبر بوت تيليجرام سهل الاستخدام.
* **تصميم هيكلي:** كود منظم وقابل للتوسع (Modular Architecture).

## 🛠 المتطلبات التقنية
* Python 3.8+
* مكتبة `nmap` مثبتة على النظام (Linux/WSL).
